#02产品与工具Claude

Claude 下周起在网页、桌面和手机端默认开启 auto mode，覆盖 Pro、Max 和 Team 套餐。这个模式不再一步步问用户批准，改由自动检查拦住高风险操作，想回手动随时能切。官方引用的 Claude Code 更新说，auto mode 用单独的分类器审查 shell 命令，测试里拦下了 89% 的危险命令，手动批准是 14%。

↗X
#03产品与工具OpenAI

OpenAI 的 Decisions API 正式可用，底子是 GPT-6 Luna，专做分类、路由、评分这类答案有限的小决策。官方说速度最高比通过 Responses API 用 GPT-6 Luna 快 10 倍，主打低延迟低成本。

↗OpenAI
#04产品与工具Replit

Replit 推出 Monitoring Agent，相当于给应用配了个自主值班的工程师。它会读生产日志和指标，自己去查报错、变慢和部署失败；开了自动修复就验证修复结果并发邮件汇报，再开自动发布还能把修复直接部署上去。这是在之前的 App Monitoring 基础上做的，在应用的 Publishing 设置里开启。

↗Replit

↗禾赛科技
#06行业PHPSECURITY

PHP 核心的两个内存损坏漏洞 PHP2Shell 披露，是 Calif、Wiz 和 OpenAI 的研究者用 AI 发现的，OpenAI 这边用的是 Patch the Planet 项目里的 GPT-5.6 Sol，并和 PHP、Calif、Wiz 一起验证、写补丁。披露前四天黑客已经在利用，Cloudflare CEO 说公告前 10 小时就有数千次尝试，公告后两小时涨到数十万，现在到数百万级。NSA 建议来不及更新的机构先把系统离线。

↗Latent Space
